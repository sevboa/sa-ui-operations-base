# Инструкция по релизу версии 1.1.0

## Шаги для публикации версии 1.1.0

### 1. Проверка изменений

Убедитесь, что все изменения готовы:

```bash
git status
```

### 2. Добавление всех изменений

```bash
# Добавить все измененные и новые файлы
git add .

# Или выборочно:
git add sa_ui_operations/
git add pyproject.toml setup.py
git add README.md PLUGIN_GUIDE.md DEV_DEBUG.md
git add dev_run.py examples/
```

### 3. Создание коммита

```bash
git commit -m "Версия 1.1.0: Добавлена система настроек, общие настройки, выполнение в потоках

- Добавлена автоматическая система настроек через get_settings()
- Поддержка общих настроек для всех плагинов с визуальным разделением
- Выполнение плагинов в отдельных потоках (не блокирует UI)
- Добавлены кнопки остановки и настроек с индикатором статуса
- MainWindow теперь требует organization_name и application_name для изоляции настроек
- Добавлено руководство по созданию плагинов (PLUGIN_GUIDE.md)
- Добавлен скрипт для отладки (dev_run.py)
- Консоль открыта по умолчанию
- Исправлены баги с сохранением состояния кнопки настроек"
```

### 4. Отправка изменений в ветку develop

```bash
git push origin develop
```

### 5. Создание и отправка тега (если тег еще не создан)

Если тег уже создан локально:
```bash
git push origin v1.1.0
```

Если тег нужно создать:
```bash
# Создать аннотированный тег
git tag -a v1.1.0 -m "Версия 1.1.0: Система настроек, общие настройки, выполнение в потоках"

# Отправить тег
git push origin v1.1.0
```

Или отправить все теги сразу:
```bash
git push origin --tags
```

### 6. Создание Release на GitHub (рекомендуется)

1. Перейдите на https://github.com/sevboa/sa-ui-operations-base/releases/new
2. Выберите тег `v1.1.0`
3. Заголовок: `Версия 1.1.0`
4. Описание (можно скопировать из коммита выше)
5. Нажмите "Publish release"

### 7. Проверка установки новой версии

После публикации можно проверить установку:

```bash
pip install git+https://github.com/sevboa/sa-ui-operations-base.git@v1.1.0
python -c "from sa_ui_operations import __version__; print(__version__)"
# Должно вывести: 1.1.0
```

## Важные изменения в версии 1.1.0

⚠️ **Несовместимость с версией 0.1.0:**

- `MainWindow` теперь требует обязательные параметры `organization_name` и `application_name`
- Старые скрипты нужно адаптировать под новый API

## Быстрая команда (все сразу)

```bash
# Добавить все изменения
git add .

# Создать коммит
git commit -m "Версия 1.1.0: Система настроек, общие настройки, выполнение в потоках"

# Отправить в develop
git push origin develop

# Отправить тег (если уже создан)
git push origin v1.1.0
```
