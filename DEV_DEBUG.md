# Отладка и разработка

## Запуск без установки

Для разработки и отладки с брейкпоинтами используйте скрипт `dev_run.py`:

```bash
python dev_run.py
```

Этот скрипт:
- Автоматически добавляет корневую директорию проекта в `sys.path`
- Позволяет импортировать модули напрямую из исходников
- Не требует установки пакета через `pip install`
- Поддерживает отладку с брейкпоинтами в IDE

## Отладка в IDE

### VS Code / Cursor

1. Откройте проект в VS Code/Cursor
2. Установите брейкпоинты в нужных местах кода
3. Запустите `dev_run.py` через отладчик:
   - Нажмите `F5` или выберите "Run and Debug"
   - Выберите конфигурацию "Python: Current File"
   - Или создайте конфигурацию `.vscode/launch.json`:

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: Debug dev_run.py",
            "type": "debugpy",
            "request": "launch",
            "program": "${workspaceFolder}/dev_run.py",
            "console": "integratedTerminal",
            "justMyCode": false
        }
    ]
}
```

### PyCharm

1. Откройте проект в PyCharm
2. Правой кнопкой на `dev_run.py` → "Debug 'dev_run'"
3. Установите брейкпоинты и отлаживайте

### Отладка через pdb

```bash
python -m pdb dev_run.py
```

## Структура проекта

```
sa-ui-operations-base/
├── dev_run.py          # Скрипт для запуска без установки
├── sa_ui_operations/   # Исходный код библиотеки
│   ├── base_ui.py      # Основной UI
│   ├── plugin_system.py # Система плагинов
│   ├── settings.py     # Система настроек
│   └── plugins/         # Примеры плагинов
└── examples/           # Примеры использования
```

## Изменения в коде

После изменения кода в `sa_ui_operations/`:
- Просто перезапустите `dev_run.py` - изменения применятся автоматически
- Не нужно переустанавливать пакет

## Проверка импортов

Если возникают проблемы с импортами, убедитесь что:
1. Вы находитесь в корневой директории проекта
2. Виртуальное окружение активировано
3. Зависимости установлены: `pip install -r requirements.txt`

## Альтернативный способ запуска

Можно также запустить напрямую через модуль:

```bash
# Из корневой директории проекта
python -m sa_ui_operations.main
```

Но для этого нужно убедиться, что модуль доступен в Python path.
