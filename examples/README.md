# Примеры использования

Эта папка содержит примеры использования библиотеки `sa-ui-operations-base`.

## Запуск примеров

Примеры не устанавливаются вместе с библиотекой. Для их запуска:

1. Установите библиотеку:
   ```bash
   pip install -e .
   ```

2. Запустите пример:
   ```bash
   python examples/example_usage.py
   ```

## Создание своих примеров

Создайте файл в этой папке и используйте библиотеку:

```python
from sa_ui_operations import MainWindow, PluginRegistry
# ... ваш код
```
