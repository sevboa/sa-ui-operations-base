# Changelog

## 1.2.0

- Добавлены группы настроек (`GroupSetting`) с независимыми наборами значений по режимам.
- Расширены типы настроек (regex для строк, min/max для чисел, список строк, путь к файлу).
- Обновлен UI настроек (валидация, подсказки, выравнивание и размеры полей).
- Обновлены инструкции установки: установка из ZIP вместо Git.
